## Highlights

- **Git worktree workspaces** — create, open, refresh, and safely remove Git worktrees from BLXCode, including Remote SSH workspaces.
- **Titlebar Run menu** — BLXCode can scan the active workspace for common run, dev, test, build, and debug commands, then start one in a new terminal slot.
- **Plugin packages** — a new **Settings -> Plugins** tab manages built-in and GitHub-installed plugin packages, with enable, disable, and remove controls.
- **Interactive Mermaid diagrams** — pan and zoom diagrams in the gallery and in `.mmd` / `.mermaid` file previews, with controls for zooming and reset.
- **Mermaid source inspector** — open a CodeMirror editor beside or below a diagram, make edits, and see the rendered result update without losing invalid drafts.

## New

### Git worktrees

- Create worktree-backed workspaces from the Create Workspace flow by choosing a branch, start point, and path.
- Use the titlebar **Worktree Management** menu to list, open, create, refresh, and remove worktrees for the active workspace.
- Remote SSH workspaces support the same worktree flow, and remote terminals now start in the selected worktree directory.
- The BLXCode Agent understands the active worktree and can help list or create worktree workspaces, with a confirmation step before creating or opening one.

### Plugins and Run menu

- BLXCode now has an app-data-backed plugin package registry for built-in and GitHub-installed packages.
- Runtime plugins can contribute command detectors without running plugin code.
- Built-in runtime plugins detect common project commands for Node package managers, Rust/Cargo, Go, CMake/Make, shell scripts, and JavaScript or TypeScript entry points.
- The new titlebar **Run** menu scans local and SSH-remote workspaces through enabled runtime plugins, groups detected commands, and launches the selected command in a visible terminal.
- GitHub plugin installation supports repository or package-directory URLs, optional refs, validation, progress polling, and rollback on failed installs.

### Mermaid diagrams

- The Diagram gallery and Mermaid file previews now share a smoother interactive viewport with drag-to-pan, wheel zoom, toolbar zoom, and reset.
- Diagram pan and zoom state survives live re-renders, so editing or refreshing no longer snaps the view back unexpectedly.
- The Mermaid source inspector uses CodeMirror and adapts to the available space: a resizable side panel on wide panes and a bottom drawer on narrow panes.
- Persisted plan diagrams now have explicit **Save** and **Revert** actions that update the diagram file while keeping its metadata intact.
- Ad-hoc chat timeline diagrams can be edited and exported in memory, without pretending they are saved to a plan.

## Good to know

- Worktree removal is guarded: BLXCode refuses to remove dirty worktrees.
- Runtime plugins discover commands; they do not execute plugin code.
- Mermaid files still follow the existing editor safety rules, including workspace-root sandboxing, protected-folder checks, and too-large-file handling.
- The full technical changelog lives in `CHANGELOG.md`.
